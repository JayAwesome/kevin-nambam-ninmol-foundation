## Missing Image Categories

- Real healthcare or medical outreach images: checkups, wellness screening, medical partners, first-aid support, health education in action.
- Real trustee and leadership headshots: chairman, secretary, treasurer, management team, volunteers.
- Approved beneficiary story portraits: only use with consent and safeguarding review.
- Project before-and-after photos: useful for future Impact page evidence.
- Formal document visuals: annual report covers, financial summary PDFs, registration documentation screenshots if approved for public sharing.

## Alt Text Improvements Implemented

- Program cards now use descriptive alt text from data where available.
- Program detail pages now use descriptive program alt text.
- Impact gallery cards now use descriptive alt text.
- Leadership cards now use descriptive role/context alt text.
- Home hero alt text now describes the actual image content.

## Caption Recommendations

- Keep captions tied to visible action: coaching, relief supplies, recognition, community visit, wellbeing talk.
- Avoid claiming medical service where the image only shows a talk or gathering.
- Avoid using founder portraits for program results unless the image shows direct program delivery.
- Use inspiration images only for inspiration/origin/mentor storytelling, not generic program content.

## Remaining Recommendations

- Replace placeholder board/trustee images with real approved headshots as soon as available.
- Add true healthcare outreach photographs before presenting healthcare as a major visual program pillar.
- Continue using descriptive filenames for new media, for example `school-book-support.jpeg` or `medical-outreach-checkup.jpeg`.
- Preserve consent and safeguarding rules before publishing children or beneficiary close-ups.
